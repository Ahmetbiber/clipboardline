# Native text and file transfers

Enter copies and closes browsing windows; Control-Enter explicitly pastes into
the exact previously focused external editable field on Windows. The matching
Mac shortcuts use Command. These transfers retain batch order and release focus
back to the intended application. Secure, read-only, closed or changed targets
are rejected before the clipboard is written.

For drag and drop, Windows keeps ordinary text/link dragging as text insertion.
**Alt+drag** offers one exported file per selected text/link instead. A tooltip
on these cards exposes the gesture. Images and mixed batches containing an image
use native file dragging. Text copies use UTF-8 `.txt`; Windows link copies use
native Internet Shortcut `.url`, the Windows counterpart to Mac `.webloc`.
Original images remain unchanged.

The distinction is an Electron API limitation: `webContents.startDrag` exposes
`file`/`files` and `icon`, with no simultaneous Unicode-text/custom-data argument.
Routing every text drag through that API would remove insertion into ordinary
text editors. Mac AppKit can advertise text and file representations in the same
drag. This Windows release therefore makes file export explicit with Alt while
preserving the default text workflow; it does not claim identical native drag
representation capabilities.

Generated files live in a private per-user staging folder with unique batch
names and index/UUID-only file names. They never use copied values, titles or
URLs as file names. The backend captures the ordered selected IDs and payloads,
rejects trashed or malformed entries and validates managed image files. Existing
staging symlinks are rejected. Cleanup deletes only strictly verified generated
batches, never original media or unknown files; it runs at quit and the next
launch to recover incomplete batches after a crash.

Acceptance checks distinguish renderer gesture dispatch, actual backend/native
handoff and generated bytes from an external drop. Capturing the native handoff
in an isolated test proves the file payload/order without claiming that Explorer
or another editor received an actual drag.
