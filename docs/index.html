Three shelves. One memory.

From quick copy to a lasting collection.

Use the shelves for the next thing you need. Use Library for the things you want to keep. Pinning, folders and tags bridge the two without creating a second set of favorites.

Your first five minutes

  1. Install and open

    Download the latest Mac release, move the app to Applications and open it. ClipBoardLine lives in the menu bar.

  2. Choose what to collect

    In Settings → Sources, enable image or text capture if wanted. Standalone-link capture defaults on and can be disabled. Choose screenshot handling separately.

  3. Browse without breaking your flow

    Press ⌃⌥T, use the arrow keys and press Space to preview. Enter copies and closes the shelves; focus returns to the previous app.

  4. Keep the useful things

    Press P to pin, ⇧P to choose a folder or ⌥P to add a useful name. Tagged or filed records remain after normal history expires.

  5. Make it your own

    Set retention for each content type, record shortcuts, choose colors and toggle automatic update checks in Settings.

Full feature inventory

Everything the app does, in one place.

A source-based guide to current macOS behavior. Features below describe the application, not a promise that every receiving app supports every clipboard representation.

01

Three independent shelves

Browse Images, Texts and Links as separate horizontal rows. Toggle each row, switch the active shelf, filter pinned items and scroll through older copies. Fresh openings return each visible row to its first item.

02

Screenshot and clipboard capture

Handle screenshots instantly, watch up to three additional image folders, and optionally collect copied images or text. Clipboard image and text collection are independent opt-ins. Text and link copies arrive silently without opening the shelves.

03

A local Library

A resizable native window with grid and list views, a folder/tag sidebar and an editable inspector. Create notes, edit titles and content, and organize images, text and links together. Full screen is optional.

04

Pin, name, file and tag

Pin and favorite are one action. Pins, folder membership or tags retain an item beyond ordinary history expiry. Use nested virtual folders and multiple tags; name-and-pin supports a sequential batch workflow.

05

One shelf search

The centered search field searches all currently visible shelves: text, link details, titles, notes, tags and recognized text in images. Hidden shelves are excluded. Browse results without opening Library.

06

OCR and visual search

Apple Vision OCR and MobileCLIP-S2 run on the Mac. Library offers text/OCR, visual, or combined search, plus type, date, domain, tag, folder and pinned filters. Visual descriptions work best in English.

07

Link cards with context

A standalone copied web URL goes to Links; a paragraph containing URLs stays text. Optional enrichment adds website or YouTube titles, authors and thumbnails. Open the selected link in your browser.

08

Borderless previews

Space opens images, editable text and link previews. Shelf previews can move across content types without closing the window. Image zoom runs from initial fit to 400%; pinch, wheel and drag-to-pan are supported.

09

Editable markup and crop

Pen, translucent marker, rectangle, ellipse, arrow, line and text tools share the top preview toolbar. Move/resize marks, change styles and undo. Crop non-destructively; original files and editable annotations remain available.

10

Copy, paste, drag and export

Copy selected batches in order, drag multiple items, export copies, or explicitly paste into the editable field previously focused in another app. Image copies include full-resolution crop/markup. Multiple-image paste depends on the destination app.

11

History without repeated text cards

Configure image, text and link retention separately: 1, 3, 7, 15 or 30 days, with 30 days as the default. Re-copying equivalent text refreshes one current entry instead of filling the shelf with duplicates; saved organization is preserved.

12

Take down and recover

S removes the selection and selects the next surviving item. Saved records remain in Library; temporary copies enter recoverable Trash. Backspace restores the latest shelf removal, including batches, during the current app session. External original files are preserved.

13

Keyboard-driven Actions

Search the contextual Actions bar for organization, navigation, image editing, Library views, settings and updates. Commands show current shortcut assignments and operate on the item or ordered batch captured when the bar opened.

14

A Mac interface you can tune

Small, medium and large cards; soft shelf colors or neutral glass; configurable reveal behavior, full-screen-app visibility, sounds and login launch. Choose the app language independently of macOS. Most browsing shortcuts can be remapped or disabled.

15

Native signed updates

Sparkle presents release notes, downloads and installation. Official public updates need no GitHub account or token. Automatic checks can be disabled; when enabled they run hourly while the app is running. Download and installation require your action.

Keep your hands on the keyboard.

These are defaults. Settings → Keyboard shortcuts can change or disable browsing bindings and global hotkeys. Single-letter keys belong to the app only while browsing; text fields keep normal typing. ⌘ Command · ⌥ Option/Alt · ⌃ Control · ⇧ Shift.

Local collection. Explicit connections.

Stored on your Mac

History, folders, tags, notes, thumbnails and search indexes live locally. ClipBoardLine does not provide cloud sync. Local storage is not a password vault; choose what you copy and retain.

Image and text capture are opt-in

Turning a watcher on skips the previous clipboard contents. Concealed, transient and autogenerated clipboard markers are checked, Finder file copies are skipped, and the app suppresses its own copies.

OCR and visual search stay on-device

Image recognition, visual embeddings and search queries run locally. Runtime OCR/visual search does not upload images or query text.

Link enrichment is optional network access

Enabled enrichment contacts the linked website or YouTube for metadata and thumbnails. Local addresses and URLs with known secret parameters are excluded; disable enrichment in Sources if unwanted.

Updates use the network, not a client token

The official Sparkle feed and archives are public and signed. Checks are configurable; downloads and installation need your action. This update channel does not require a GitHub login.

Paste has a separate permission

⌘Enter needs the app’s macOS Accessibility permission. It validates the original editable field and refuses secure or changed targets. Ordinary copying does not require that permission.

Recoverable removal, preserved originals

Temporary records can be recovered from Library Trash. External source images are not deleted by taking them off the shelf. Expiry is separate for images, text and links.

A native Mac app today.

The current application uses Swift, AppKit, SwiftUI, Vision and Core ML. It supports macOS 14 or later on Apple silicon and Intel. A separate Windows source implementation is also included; support gaps and native validation status are explained in the comparison below.

For developers

The public source snapshot is separate from the official binary/update repository. Xcode with a macOS SDK and Python 3 are needed for the commands below. Optional model preparation downloads pinned MobileCLIP-S2 assets and compiles them locally; Vision OCR works without these models. Use the repository’s development guide for packaging. Official release signing keys, credentials and user history are not included.

git clone https://github.com/orkunisitmak/clipboardline-desktop.git
cd clipboardline-desktop
swift package resolve
swift test
bash scripts/build-community.sh
# Optional offline semantic models:
CLIPBOARDLINE_BUNDLE_MODELS=1 bash scripts/build-community.sh
# Optional isolated UI harness:
bash scripts/build-ui-tests.sh

The UI harness uses synthetic fixtures and separate preferences. It does not install the app or enable clipboard collection. Official signed releases are built by the maintainer; cloning the source does not grant the official signing identity.

Platform support and current gaps

The Windows source implementation is included; native acceptance is tracked separately for source, packaged and installed Windows builds. A passing JavaScript test is not proof of native paste or installer behavior. Check the Windows CI result and release assets before treating a build as validated. macOS and Windows data stores are separate; cross-device sync and automatic migration between them are not provided.

Normal operating-system approval may be required on first open. The Mac build uses a persistent project certificate rather than Apple Developer ID/notarization; the Windows installer is not Authenticode-signed. Update signatures and hashes establish the project update channel, not Apple or Microsoft publisher certification. Use the documented release assets and normal OS approval; do not disable system protections.
